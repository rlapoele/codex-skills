# Changelog

All notable changes to this project are documented in this file.

## [0.1.0] - 2026-10-08

### Added

- Initial public release of the guarded `domain-modeling` skill.
- Explicit-only invocation for predictable activation.
- Repository-first glossary and documentation conventions.
- Authorization boundaries for documentation changes.
- ADR qualification and structured handoff to `agent-skills:documentation-and-adrs`.
- ADR lifecycle safeguards for accepted, superseded, deprecated, and draft decisions.
- Portable plugin and repository marketplace metadata.
- Deterministic local and continuous validation.
